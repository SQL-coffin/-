# 树莓派遥控车避让

树莓派 RC 模型车单目视觉自动避障。摄像头看前方地面，把"不是地面"的部分当作障碍，用人工势场算出转向和油门，通过 pigpio 输出舵机和电调的 PWM。

## 工作原理

1. **取图**：优先用 Picamera2，失败时回退到 `cv2.VideoCapture(0)`，分辨率 320x240。
2. **地面分割**：取画面底部中间一块作为地面样本，计算 HSV（H/S 通道）直方图，对整幅图做反投影得到地面掩码。
3. **防遮挡**：维护一个缓慢更新的参考地面直方图。障碍贴近车头、盖住样本区时，改用参考直方图，调试窗口显示 `SAMPLE!`。
4. **逆透视**：逐列从下往上找第一个非地面像素作为障碍接触点，按针孔模型（视场角 62°、相机高 0.12m、俯角 20°）投影到车体坐标。
5. **规划**：人工势场（目标引力 + 障碍斥力）得到转向角；越近越慢；正前方被顶住或左右斥力抵消时自动倒车脱困。

## 接线

| 树莓派（BCM 编号） | 接到 |
|---|---|
| GPIO18（物理 12 脚） | 转向舵机信号线（通常白/黄/橙） |
| GPIO13（物理 33 脚） | 电调信号线（通常白/黄） |
| GND（如物理 6、14 脚） | 舵机和电调的地线（黑/棕） |

**舵机和电调只接信号线和地线，红线（5V）不要接到树莓派的 5V。** 舵机由电调的 BEC 供电（舵机红线接接收机/电调一侧，保持原车接法），树莓派单独用充电宝或降压模块供电。所有设备必须共地，否则信号不可靠。

## 安装

```bash
sudo apt install -y python3-picamera2 python3-opencv python3-numpy pigpio python3-pigpio
sudo systemctl enable --now pigpiod     # 或每次手动 sudo pigpiod
```

不在树莓派上（只跑测试）时：`pip install -r requirements.txt`。

## 运行

```bash
python3 rc_avoid.py --dry-run --debug   # 第一步：不输出 PWM，只看地面掩码和方向箭头对不对
python3 rc_avoid.py --debug             # 第二步：把车架空（轮子离地），确认舵机和油门方向
python3 rc_avoid.py                     # 确认无误后落地运行
```

启动时让车停在干净的地面上，参考地面直方图取自开头几帧。电调会先在中位解锁 2 秒。按 Ctrl+C 或收到 SIGTERM 会先回中再退出。

## 标定

所有参数在 `rc_avoid.py` 开头的 `Config` 里，标了 `[标定]` 的需要按实车修改，重点是：

- `cam_height_m`、`cam_pitch_deg`、`hfov_deg`：相机安装高度、俯角、视场角。可在地上放已知距离的标记校对。
- `steer_center_us`、`esc_center_us`：车走不直或电调不停就调中位（默认 1500µs，行程 ±400µs）。
- `steer_reverse`、`esc_reverse`：舵机或油门方向反了就设为 `True`。
- `max_throttle`、`reverse_throttle`：先从小值试起。
- `esc_double_tap_reverse`：带刹车的电调需要"反向、回中、再反向"才会倒车，默认开启；可直接倒车的电调设为 `False`。
- `backproj_thresh`、`k_rep`：地面识别和避障灵敏度。

## 测试

```bash
python3 test_avoid.py      # 用合成图像（灰色地面 + 红色障碍）测感知和规划
```

测试覆盖逆透视、左右避让、近处减速、倒车时序和样本区被完全遮挡的情况，不需要树莓派。摄像头和 PWM 部分没有在实车上测过。

## 已知限制

- 障碍只**部分**盖住底部样本区时，样本直方图会混入障碍颜色，但与参考的相关度可能仍高于阈值，于是障碍的大部分被当成地面，识别出的障碍点会大幅减少（合成测试里墙盖住样本区约三分之一时只剩 1 个点，仍触发了倒车，但余量很小）。可以把 `ref_hist_corr_min` 调高，或缩小样本区。
- 只适合颜色较均匀的地面；地面花纹复杂或与障碍颜色接近时效果会变差。
